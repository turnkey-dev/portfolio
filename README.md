## Навыки
- **Языки:** Python, C#, JavaScript, SQL, PowerShell
- **Бэкенд и веб:** Django, FastAPI, WSGI, Jinja2, PostgreSQL, SQLite, REST, WebSocket
- **Инфраструктура:** Docker Compose, Nginx (mTLS), Caddy, Gunicorn, Let's Encrypt, резервное копирование и откат, работа в закрытом контуре
- **Десктоп:** PyQt5, WinForms, Electron, tkinter, приложения в трее, сборка в один exe (PyInstaller)
- **Компьютерное зрение и ИИ:** обучение своих моделей (TensorFlow → ONNX, CRNN + CTC, U-Net, классификаторы), сбор и разметка датасетов, запуск на CPU через onnxruntime, YOLOv8, OpenCV, локальные LLM/OCR (LM Studio, llama.cpp), вызов нативных библиотек через ctypes
- **Безопасность:** роли и права, 2FA (TOTP), X.509/mTLS, журналы аудита, вынос секретов из кода
- **Документы:** генерация DOCX/PDF/XLSX по шаблонам
- **Качество:** автотесты (pytest, unittest), регрессионные наборы правил, smoke-проверки после релиза, инструкции для пользователей
