# Антиспам-бот для Telegram с объяснимым фильтром

Бот модерирует группы: находит спам с «подработкой», вербовкой в крипто-схемы, платными отзывами и похожие рассылки. Такие сообщения он удаляет, а отправителя банит.
Решение принимает не один «стоп-ключ», а **набор независимых сигналов с весами**. Для каждого срабатывания в журнал пишется причина.

## Как устроен фильтр (`spam_filter.py`)
- **Нормализация текста.** NFKC, `ё→е`, удаляются невидимые символы, а латинские двойники внутри кириллических слов заменяются кириллицей (`рaбoтa` → `работа`). Так спамер не обойдёт правила подменой букв.
- **Взвешенные правила:** вербовка (3), подработка (2), «ничего сложного» (2), оплата/наличные (3), суммы (2), «за 2 часа» (2), «пиши в лс» (1), «впишись в тему» (4).
- **Кампанийные правила** срабатывают только при совпадении нескольких признаков сразу: крипта + контакт + обучение «с нуля», обменник за наличные, «оставь отзыв — вернём деньги».
- **Защита от ложных срабатываний.** Нужно и вербовочный контекст, и стимул, и порог по сумме весов. Порог настраивается: 6 — строже, 9 — мягче.
- **Режим `DRY_RUN`** только записывает срабатывания в журнал. Так новые правила можно обкатать без банов.

## Бот (`bot.py`)
- Работает на чистом Bot API через long polling (`getUpdates`), без сторонних библиотек.
- При старте проверяет права администратора (`can_delete_messages`, `can_restrict_members`).
- Учитывает белый список пользователей и список разрешённых групп. Команда `/chatid` показывает ID группы.
- Блокировка не даёт запустить второй экземпляр.
- Окно управления на PowerShell/WinForms (`bot_window.ps1`): запуск и остановка, журнал «Что происходит», выбор групп.

## Окно управления

Дважды нажмите файл **Open Bot.vbs** в папке проекта. Откроется окно с двумя кнопками: **Запустить бота** и **Остановить бота**. Открытие окна само по себе не запускает модерацию.

Вкладка **Что происходит** показывает понятные сообщения об удалениях, банах, тестовых срабатываниях и ошибках. **Технические логи** содержит подробности текущего запуска; постоянная история модерации остаётся в `data/moderation.log`. Обычные сообщения в журнал не записываются. Настройки и режим берутся из `.env` при запуске. Закрытие окна останавливает запущенный через него процесс бота. Компьютер должен быть включён и иметь доступ к интернету.

Если бот был запущен через PowerShell раньше, сначала остановите его там с помощью Ctrl+C. Окно управляет только тем процессом, который запустило само. Повторный запуск обновлённого бота из той же папки защищён блокировкой.

В поле **Группы для проверки** вставьте один или несколько отрицательных ID через запятую, пробел или с новой строки и нажмите **Сохранить группы**. Повторы убираются автоматически. ID можно получить командой `/chatid@your_bot` в группе при работающем боте. Для проверки всех групп есть явный переключатель **Все группы бота**. Пустое поле без этого переключателя не сохраняется. Чтобы изменить список, сначала остановите бота; кнопка запуска также сохраняет и проверяет введённые ID. Бот должен иметь права администратора в каждой выбранной группе.

Если Windows запрещает запуск `.vbs`, откройте PowerShell и выполните:

```powershell
powershell -NoProfile -STA -ExecutionPolicy Bypass -File ".\bot_window.ps1"
```

Удаляет сообщения с предложениями сомнительной подработки и бессрочно банит их авторов. Работает на Python 3.10+ без установки сторонних библиотек и без платных сервисов.

## Запуск на вашем компьютере

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot`, задайте имя и получите токен.
2. В папке проекта скопируйте `.env.example` в `.env`. Вставьте токен после `BOT_TOKEN=`. Не публикуйте этот файл.
3. Добавьте бота в нужную группу и назначьте администратором с правами **удаления сообщений** и **блокировки участников**. Бот-администратор получает сообщения группы независимо от Privacy Mode: [официальная справка](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).
4. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start.ps1
   ```

   Скрипт использует установленный Python или Python из локальной установки Codex. На другом компьютере потребуется Python 3.10+. Альтернативный запуск: `python bot.py`.
5. Отправьте `/chatid` в группе. При желании впишите полученное отрицательное число в `ALLOWED_CHAT_IDS` и перезапустите бота. Можно указать несколько групп через запятую. Пустое значение включает проверку во всех группах бота.

По умолчанию включено **удаление + бан** (`DRY_RUN=false`). Чтобы сначала проверить срабатывания без санкций, установите `DRY_RUN=true`. Журнал находится в `data/moderation.log`: `TEST` означает только тест, `OK deleteMessage` — удаление, `OK banChatMember` — бан, `FAIL` — неудачное действие. Тексты сообщений и токен в журнал не записываются.

Окно с работающим ботом должно оставаться открытым, компьютер — включённым с доступом к интернету. Для круглосуточной работы перенесите проект на постоянно работающий компьютер или сервер. Остановка: Ctrl+C. Не запускайте два экземпляра с одним токеном.

## Как работает фильтр

Бот ищет сочетания признаков: набор людей, подработка, обещание оплаты, сумма, короткая смена, «ничего сложного», приглашение «вписаться в тему». Примеры из скриншотов включены в тесты. Обрабатываются текст, подписи к медиа и редактирование сообщений. Невидимые символы, «под работка» и часть замен русских букв похожими латинскими нормализуются.

Дополнено по образцам от 19 сентября: набор в криптобизнес с контактом, простые криптозадачи с обучением и контактом, платные отзывы/фидбек, доставка алкоголя с денежным вознаграждением и «бутылкой за помощь». По выбранному пользователем образцу также блокируется поиск покупки криптовалюты за наличные через обменник. Само упоминание криптовалюты, отзывов или переезда не является достаточным признаком. Контакты из образцов не занесены в чёрный список: правила работают и при смене имени пользователя. Суммы распознаются также в форматах `1000р`, `1000p`, `3000₽`.

- `SPAM_THRESHOLD=7` — стандартный порог; `9` — меньше срабатываний; `6` — больше.
- `WHITELIST_USER_IDS` — числовые ID исключённых пользователей через запятую.
- Администраторы и владелец группы исключены автоматически; перед санкциями проверяется текущий статус отправителя.
- Сообщения от имени каналов и анонимных администраторов пропускаются: их нельзя безопасно связать с конкретным человеком.
- Все настройки применяются после перезапуска. Сами правила находятся в `spam_filter.py`.

Это фильтр по признакам, а не безошибочное определение мошенничества. Настоящее объявление о найме тоже может совпасть с правилами, а новый вид спама — пройти. Текст внутри картинок и голосовые сообщения не распознаются; ссылки сами по себе не приводят к бану. Для группы с разрешёнными вакансиями сначала используйте тестовый режим и исключения для доверенных авторов.

Бан не имеет срока. Разблокировать человека можно вручную в настройках группы → заблокированные пользователи. В супергруппе Telegram при бане также удаляет сообщения этого пользователя; восстановить удалённые сообщения бот не сможет. Удаление старых сообщений ограничено Telegram (обычно 48 часов). См. [banChatMember](https://core.telegram.org/bots/api#banchatmember) и [deleteMessage](https://core.telegram.org/bots/api#deletemessage).

Бот получает новые обновления и доступную очередь Telegram, а не всю историю группы. После перезапуска продолжает с сохранённого обновления. При временной ошибке повторяет обработку; постоянные ошибки записывает в журнал. Используйте отдельного бота без настроенного webhook. Смена ID группы при преобразовании в супергруппу требует обновления `ALLOWED_CHAT_IDS`, если список заполнен.

## Проверка

```powershell
python -m unittest -v
```

Тесты не обращаются в Telegram: проверяют примеры спама и обычных сообщений, удаление и бан, защиту администраторов, исключения, подписи, редактирование и ошибки API.
